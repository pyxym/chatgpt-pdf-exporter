# Privacy Policy

## Data Collection

ChatGPT PDF Exporter does not collect, store, or transmit any personal data or user information.

## Data Processing

- All data processing occurs locally in your browser
- No data is sent to external servers
- No analytics or tracking is performed
- No user accounts or registration required

## Permissions

The extension requests the following permissions:

### activeTab
- **Purpose**: Access the current ChatGPT tab to extract conversation content
- **Scope**: Only active when you're on chatgpt.com or chat.openai.com
- **Data**: Reads conversation content only when you initiate an export

### downloads
- **Purpose**: Save exported files (PDF, HTML, text) to your computer
- **Scope**: Only used to download files you explicitly request
- **Data**: No data is stored or transmitted

## Data Security

- No network requests are made to external servers
- All conversation data remains in your browser
- Generated files are saved directly to your local machine
- No data persistence beyond the export process
