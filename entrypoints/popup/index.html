📄 ChatGPT PDF 저장

ChatGPT 페이지에서 대화 내용을 PDF로 저장할 수 있습니다.

사용 방법:

  1. ChatGPT 페이지 (chatgpt.com)로 이동
  2. 상단 네비게이션의 "PDF Export" 버튼 클릭
  3. 내보내기 형식 선택:
    • PDF: 고품질 PDF 파일로 저장
    • HTML: 웹 페이지 파일로 저장
    • 텍스트: 일반 텍스트 파일로 저장
  4. 메시지 범위 선택:
    • 전체 대화: 모든 메시지 포함
    • 선택된 메시지: 원하는 메시지만 선택
  5. 추가 옵션 설정:
    • 타임스탬프 포함
    • 사용자 정보 표시
    • 깔끔한 포맷 적용
    • 사용자 정의 제목
  6. "생성하기" 버튼 클릭

메시지 선택 방법:

  • 각 메시지 옆의 체크박스 클릭
  • 선택된 메시지는 하이라이트 표시
